# IMDb + TMDb Dataset Access
This project uses publicly available datasets from IMDb and TMDb.
Due to licensing restrictions and file size (≈9.95GB), the dataset cannot be included in this repository.
## How to Download
### IMDb Official Dataset:
Download from:
https://datasets.imdbws.com/
Files required:
- title.basics.tsv.gz
- title.ratings.tsv.gz
- title.crew.tsv.gz
- title.principals.tsv.gz
- title.akas.tsv.gz
### TMDb Metadata:
Download from:
https://www.themoviedb.org/tv/documentation/api
- movies_metadata.csv

## After Downloading
Place all downloaded files into this folder:
`/path/to/your/project/data/`
Ensure the files are unzipped if necessary.
## Note
Make sure to comply with the licensing terms of IMDb and TMDb when using their datasets.
